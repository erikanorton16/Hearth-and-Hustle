# Hearth & Hustle website

The one-page website for Hearth & Hustle, served by GitHub Pages at https://thehearthandhustle.com.

- `index.html`: the whole page (text, styles, and layout).
- `images/`: logo, photo, and sample screenshots (samples use made-up data).
- `CNAME`: tells GitHub Pages which domain this site uses.
- `events/`: the workshop calendar page (thehearthandhustle.com/events/) with an add-to-calendar file for each workshop.

Forms are built in Tally: contact form `xVxopJ`, online workshops waitlist `Nq5g6W`.
